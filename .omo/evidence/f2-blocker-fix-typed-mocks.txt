# F2 Blocker Fix: Typed Mocks

## Scope
Removed three `as any` TypeScript escape hatches from frontend tests identified in the F2 audit. Replaced them with properly typed mocks using the `InstrumentWithMappings` type from the API client.

## Changes
- `frontend/src/tests/Instruments.test.tsx`:
  - Imported `type { InstrumentWithMappings }` from `../api/client`.
  - Typed `mockInstruments` as `readonly InstrumentWithMappings[]`.
  - Removed `as any` casts from `vi.mocked(apiClient.getInstruments).mockResolvedValue(mockInstruments as any)`.
- `frontend/tests/Dashboard.test.tsx`:
  - Imported `type { InstrumentWithMappings }` from `../src/api/client`.
  - Added `satisfies readonly InstrumentWithMappings[]` to the inline mock array for `apiClient.getInstruments`.
  - Removed `as any` cast.
