## Recoverable Error State
The `App.test.tsx` test verifies that when the backend API returns a 500 error, the frontend catches it and displays a recoverable error state:
```typescript
  it("shows a recoverable API error when runtime loading fails", async () => {
    // Given: the backend runtime endpoint rejects the request.
    vi.spyOn(globalThis, "fetch").mockResolvedValue(
      new Response("server error", { status: 500, statusText: "Internal Server Error" }),
    );

    // When: the frontend shell renders.
    render(<App />);

    // Then: the user sees the app shell and a recoverable error state.
    expect(screen.getByRole("heading", { name: "Stock Data Monitor" })).toBeInTheDocument();
    await waitFor(() => {
      expect(screen.getByRole("status")).toHaveTextContent(
        "API request failed: Internal Server Error",
      );
    });
  });
```
